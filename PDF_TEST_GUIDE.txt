TROUBLESHOOTING:
----------------

Issue: "Failed to extract data from PDF"
Solutions:
- Ensure PDF is text-based (not scanned image)
- Check PDF is not password protected
- Try a different PDF file
- Check backend console for errors

Issue: Some fields are empty
Solutions:
- PDF format may be non-standard
- Manually enter missing data
- Extraction works best with academic papers

Issue: "No PDF file uploaded"
Solutions:
- Ensure file is .pdf format
- Check file size is under 10MB
- Try uploading again
